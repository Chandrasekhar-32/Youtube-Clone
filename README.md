# YouTube Clone

A simple YouTube clone built using HTML and CSS.

## Features
- Responsive layout
- Sidebar navigation
- Video thumbnails
- Header with search bar

## Technologies Used
- HTML5
- CSS3

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Chandrasekhar-32/Intial-Project.git
   ```
2. Open `Youtube.html` in your browser.
